Input-Ablation Experiments: which spectral properties does the CNN need?
========================================================================
5 independent runs x stratified 5-fold CV x 200 epochs; architecture and hyperparameters
identical to the CNN validation. Only the input transform differs between conditions.
Reference-constant mode: trainfold.
  Each fold's common reference constants are computed from that fold's TRAINING molecules only and
  applied to both its training and test data, so no held-out covariate defines the transformation.

INFERENCE: across-seed paired difference (control minus ablation), two-sided 95% t CI, n = runs.
Fold spread within a run is NOT the error term. Holm-Bonferroni correction is applied within each of
two pre-specified families: the 8 single-property contrasts, and the 4 cumulative contrasts.

WHAT A NONZERO CONTRAST MEANS: the feature-targeting TRANSFORMATION causes a measurable accuracy loss.
No transform is perfectly selective (shoulder removal alters FWHM; the cumulative transform increases
centroid spread), so a contrast does not isolate the targeted property as uniquely responsible.
